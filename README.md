The simulation computes the Nash Equilibrium, Social Optimum, welfare loss, and optimal Pigouvian subsidy analytically across N = 2 to 119 countries, calibrated to the 119 NDC-submitting nations at COP30. All results follow closed-form expressions derived from the model. The code evaluates and visualises these expressions rather than running a numerical optimisation. A fifth panel calibrates s* in dollar terms against three empirical Social Cost of Carbon estimates (Rennert et al., 2022; EPA, 2023; Stern, 2022).
Four simplifying assumptions are embedded. First, α is symmetric: every country receives the same marginal benefit from global abatement, abstracting from the substantial heterogeneity in climate vulnerability across nations. Second, c is symmetric: every country faces the same marginal cost coefficient, whereas the formal model allows country-specific cᵢ; the simulation therefore illustrates the symmetric baseline rather than the full heterogeneous extension. Third, costs are quadratic, implying linearly increasing marginal abatement costs: a reasonable approximation at moderate abatement levels that overstates tractability at extreme levels. Fourth, the game is static and one-shot, abstracting from the repeated nature of real COP negotiations in which reputation and reciprocity could in principle support cooperative equilibria above the Nash floor.
